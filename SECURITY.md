# Security Policy

Swapr observes keyboard modifier events, so privacy and security reports are taken seriously.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's [private vulnerability reporting](https://github.com/devleloper/Swapr/security/advisories/new) instead. Include:

- what you found and its impact;
- steps to reproduce, macOS and Swapr versions;
- a suggested fix, if you have one.

You will get an acknowledgement within a week. Once a fix is released, the advisory is published with credit, unless you prefer to stay anonymous.

## What counts

- Any way Swapr could read, retain or leak typed text.
- Any network activity by Swapr.
- Ways to make Swapr inject, block or alter input.
- Privilege or permission misuse.
